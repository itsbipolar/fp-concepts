# Concept catalog

The backlog of concept machines. Every row comes from a source (`docs/SOURCES.md`); v0 rows come from the CFP crash
notes (`sources/v0-cfp-crash-notes/`). Add new rows as new sources arrive; never delete a row, change its status.

**Scores.** HNW = relevance to high-net-worth Canadian clients (1–5). Vis = how naturally it becomes a machine (1–5).
Build = S (one mechanism, ~1 session), M (two or three mechanisms), L (dense see-through or many states).
Drift = how often its numbers change: L (structural rule), M (indexed yearly), H (indexed quarterly / politically live).
Archetypes A1–A10 are defined in `.claude/skills/fp-figures/references/metaphor-grammar.md`.

**Status:** `idea` -> `brief` -> `building` -> `verified` -> `approved` (compliance) -> `published`.
